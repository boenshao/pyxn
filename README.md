# pyxn

A Python implementation of the [Uxn virtual machine](https://100r.co/site/uxn.html) and part of the [Varvara](https://wiki.xxiivv.com/site/varvara.html) computer.

It currently implements the System, Console, File, and Datetime devices, which is enough to run command-line programs.

## Usage

Requires Python 3.14 or later.

```sh
python -m pyxn prog.rom
```
